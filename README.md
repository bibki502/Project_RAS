# Инструкция

Генератор умножителя Карацубы на C++, который создаёт Verilog-код для заданного разряда $N$


## Описание проекта

В отличие от стандартного умножения со сложностью $O(n^2)$, алгоритм Карацубы сводит умножение двух $N$-битных чисел к трем умножениям меньшей разрядности, что позволяет сократить аппаратные затраты при работе с большими разрядностями:
$$P_1 = A_1 \times B_1$$
$$P_0 = A_0 \times B_0$$
$$P_2 = (A_1 + A_0) \times (B_1 + B_0) - P_1 - P_0$$

### Конвейерная архитектура (3 такта):
1. **Такт 1:** Разделение входов $A$ и $B$ на старшие/младшие части ($A_1, A_0, B_1, B_0$) и параллельное вычисление сумм $(A_1 + A_0)$ и $(B_1 + B_0)$ с учетом разряда переноса.
2. **Такт 2:** Вычисление трёх промежуточных произведений $P_0$, $P_1$ и $P_2$.
3. **Такт 3:** Финальная сборка и сдвиг промежуточных результатов для формирования точного $2N$-битного ответа.



## ПО, использованное при разработке

* **C++ Compiler (g++ (Ubuntu 15.2.0-16ubuntu1) 15.2.0 / GCC):** Генератор Verilog-кода.
* **Icarus Verilog version 12.0 (`iverilog` & `vvp`):** Компиляция и поведенческая симуляция сгенерированного модуля Verilog.
* **VS Code / Bash:** Среда разработки и терминал Linux (Ubuntu 26.04).
* **Git (git version 2.53.0) & GitHub:** Система контроля версий.


## Инструкция по сборке и запуску

### 1. Компиляция и запуск C++ генератора

Запустите C++ генератор и введите желаемую разрядность $N$ (например, `8`):

```bash
g++ main.cpp -o prog
./prog
```
После выполнения программы в рабочей директории появится файл verilog.v.

### 2. Запуск симуляции (Testbench)
Скомпилируйте сгенерированный модуль verilog.v вместе с тестбенчем tb_karatsuba.v с помощью Icarus Verilog:
```bash
iverilog -o sim.vvp verilog.v tb_karatsuba.v
vvp sim.vvp
```
На данном примере вы увидите, что результат выводится на третий такт: 
```bash
[10000 ns]  A =  13, B =  11
[20000 ns] Takt 1 (OUT =     x)
[30000 ns] Takt 2 (OUT =     0)
[40000 ns] Takt 3 (OUT =   143) -> DONE!
tb_karatsuba.v:38: $finish called at 60000 (1ps)
```
